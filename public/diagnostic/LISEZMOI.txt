DIAGNOSTIC DES ÉCRANS SAMSUNG · 6MIC
=====================================

But
---
Mesurer en 3 minutes ce que les écrans QM55R savent afficher : moteur web,
résolution, animations, vidéos MP4 (1080p, 4K, 60 i/s, HEVC), enchaînement de
deux vidéos, son, stockage hors ligne, débit réseau, horloge et certificats HTTPS.
Le résumé final s'affiche à l'écran avec un QR code qui contient tous les résultats.


1. Mettre le dossier en ligne
-----------------------------
Copiez tout le dossier « diagnostic-ecrans-6mic » (index.html, sw.js, media/)
sur un hébergement web classique, par exemple à côté de Declinator :
    https://declinaisons.6mic-aix.fr/diagnostic/

- Un serveur web normal (Apache, nginx, hébergeur mutualisé) convient.
  Évitez « python -m http.server » : il ne gère pas la lecture partielle des vidéos.
- HTTPS est préférable : le Service Worker et le Cache API ne fonctionnent qu'en HTTPS.
  Si la page HTTPS ne s'ouvre pas sur l'écran, essayez la même adresse en http://
  (cela indiquerait un problème de certificat, ce qui est aussi un résultat utile).
- Vérifiez d'abord sur un ordinateur que l'adresse s'ouvre et que le diagnostic démarre.


2. Lancer le diagnostic sur un écran
------------------------------------
Attention : basculer l'écran sur l'URL Launcher le sort de MagicINFO le temps du test.
Notez ce qui est diffusé pour pouvoir revenir en arrière (étape 4).

  a. Télécommande : MENU > Système > Play via (ou « Lecture via ») > URL Launcher.
  b. HOME > URL Launcher Settings > Install Web App.
  c. Tapez l'adresse en minuscules, avec le numéro de l'écran à la fin :
        https://declinaisons.6mic-aix.fr/diagnostic/index.html?ecran=1
     (?ecran=2 pour le deuxième écran, etc. Ce paramètre est facultatif.)
  d. Validez, puis lancez « URL Launcher » depuis le menu HOME.

Le diagnostic démarre seul. Pendant les tests, regardez les consignes jaunes
en bas de l'écran (fluidité, bandeau rouge par-dessus la vidéo, écran noir entre
deux vidéos, bip sonore). Un court bip, au volume bas, retentit vers la fin.


3. Récupérer les résultats
--------------------------
Sur le résumé final :
  - scannez le QR code avec votre téléphone et collez le texte dans la conversation,
  - ou prenez une photo nette de l'écran entier.
Notez aussi ce que vous avez vu pendant les tests (saccades, bandeau, écran noir, bip).
La touche OK de la télécommande relance le diagnostic.


4. Remettre l'écran sur MagicINFO
---------------------------------
MENU > Système > Play via > MagicINFO.


Si l'URL Launcher refuse l'adresse
----------------------------------
Sur ces écrans, l'URL Launcher est souvent prévu pour installer une petite
application empaquetée (un fichier .wgt décrit par un fichier sssp_config.xml),
et non une simple page. Si vous voyez un message du type « Impossible de
télécharger l'application », ou un écran noir :
  - réessayez en http:// au lieu de https:// ;
  - essayez l'adresse du dossier seul : https://declinaisons.6mic-aix.fr/diagnostic/ ;
  - si le menu HOME propose un « Navigateur web », ouvrez-y la même adresse ;
  - sinon, notez le message exact : il faudra emballer le diagnostic dans une
    application .wgt signée, étape qui servira de toute façon pour le futur lecteur.


Contenu du dossier
------------------
  index.html                  la page de diagnostic (JavaScript ES5, compatible Chromium 47+)
  sw.js                       test du Service Worker (fonctionnement hors ligne)
  media/v1080p30-h264.mp4     1080p, 30 i/s, H.264, 8 Mbit/s : le format cible du projet
  media/v2160p30-h264.mp4     4K, 30 i/s, H.264, 20 Mbit/s (sert aussi au test de débit)
  media/v1080p60-h264.mp4     1080p, 60 i/s, H.264, 12 Mbit/s
  media/v1080p30-hevc.mp4     1080p, 30 i/s, HEVC (H.265)
  media/enchainement-a.mp4    test d'enchaînement, vidéo A (3 s)
  media/enchainement-b.mp4    test d'enchaînement, vidéo B (3 s)
  media/son.mp4               bip de 2 s pour le test du son
  media/photo-4k.jpg          image 4K pour le test de décodage
  media/fond-a.*, fond-b.*    visuels des tests d'animation (WebP et JPEG)
  media/test.woff2, test.woff polices de test

Le QR code est généré par la bibliothèque qrcode-generator (Kazuhiko Arase, licence MIT),
intégrée dans index.html.
